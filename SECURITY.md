# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **agentwire**, please do not disclose it publicly via GitHub issues.
Instead, please report security concerns directly to:

**Email:** shenalmohsl@gmail.com

Please provide:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact on agent tool proxying or sandboxing.

We will acknowledge receipt within 48 hours and work on a prompt patch.
